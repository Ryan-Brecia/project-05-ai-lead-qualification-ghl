# Project 5: AI Lead Qualification & GoHighLevel CRM Automation

## Overview

This project demonstrates an end-to-end AI-powered lead qualification workflow built with **n8n**, **Groq AI**, and **GoHighLevel (GHL)**.

The workflow receives lead information, uses AI to analyze and qualify the lead, then automatically creates or updates a contact and creates a sales opportunity inside GoHighLevel.

---

## Features

- AI-powered lead qualification
- Structured JSON output using AI
- Automatic contact creation/update in GoHighLevel
- Automatic opportunity creation in GoHighLevel
- Marketing Pipeline integration
- End-to-end workflow automation using n8n

---

## Workflow

```text
Manual Trigger
      │
      ▼
Edit Fields
      │
      ▼
AI Agent (Groq)
      │
      ▼
Create or Update Contact (GoHighLevel)
      │
      ▼
Create Opportunity
```
